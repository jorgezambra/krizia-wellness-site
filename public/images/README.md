# Images Directory

## Required Images

### Hero Background Image
- **Filename**: `hero-krizia.jpg`
- **Description**: Full background image of Krizia sitting on a beige/cream sofa, holding a blue and white patterned mug, wearing casual clothing (white tank top and jeans)
- **Recommended size**: 1920x1080px or larger (landscape orientation)
- **Format**: JPG or PNG
- **Style**: Warm, natural lighting with beige/neutral tones matching the site aesthetic
- **Usage**: This image will be used as the full-screen background for the homepage

**To add your image:**
1. Save your image as `hero-krizia.jpg` 
2. Place it in this folder: `public/images/hero-krizia.jpg`
3. The image will automatically appear as the background on the homepage

If the image is not found, the page will show a warm beige background color instead.
